# GCCOSS Website

This is the official website for the **Geojit CUSAT Centre of Sustainability Studies (GCCOSS)**, a collaborative initiative between Geojit Financial Services and CUSAT. The project is built using **React** and **Vite** for high performance and modern development.

---

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
